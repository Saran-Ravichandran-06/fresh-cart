# 🥕 Online Fruits & Veggies Store

An online full-stack web application that enables buyers to purchase fresh fruits and vegetables and allows sellers to manage products and orders efficiently.

This project demonstrates complete **frontend–backend integration**, **role-based access**, and **real-time database updates**.

---

## 🚀 Features

### 👤 User Roles
- Buyer
- Seller

### 🛒 Buyer Features
- View available fruits and vegetables
- Add products to cart
- Checkout and place orders
- View order history
- Cancel pending orders

### 🧑‍🌾 Seller Features
- Add new products
- Edit product details
- Delete products
- View received orders
- Manage order status

### 🔐 Authentication
- Secure login & registration
- Role-based dashboard access
