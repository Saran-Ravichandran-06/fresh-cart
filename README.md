This project demonstrates complete frontend–backend integration, role-based access, and real-time database updates.

## 🚀 Features

### 👤 User Roles
- **Buyer**: Browse products, manage cart, and place orders.
- **Seller**: Manage product catalog and track incoming orders.

### 🛒 Buyer Features
- 🍎 **View** available fruits and vegetables
- 🛍️ **Add** products to cart
- 💳 **Checkout** and place orders
- 📜 **View** order history
- ❌ **Cancel** pending orders

### 🧑‍🌾 Seller Features
- ➕ **Add** new products
- ✏️ **Edit** product details
- 🗑️ **Delete** products
- 📦 **View** received orders
- 🔄 **Manage** order status

### 🔐 Authentication
- 🔒 Secure login & registration
- 🛡️ Role-based dashboard access
